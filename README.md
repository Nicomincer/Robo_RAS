# Robo_RAS

**Ideia base**

Ele usa a ideia de uma maquina de estados onde os estados disponiveis são: BUSCAR, ALCANÇAR, AGARRAR E RECOLHER. Ele funciona através de um sensor ultrasonico que mede a distância de um objeto e com base nessa distância move os servos motores para alcançar o objeto e fecha a garra quando o objeto estiver a 12 cm de distância.
